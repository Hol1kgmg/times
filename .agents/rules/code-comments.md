# コードコメントのルール

- コメントはコードから読み取れない理由 (why) だけを書く。何をするか・どう動くかの説明は書かない。
- 書く前に「この行を消してもコードから分かるか」を確認し、分かるなら書かない。
- 残すのは背景や制約: 外部ライブラリの仕様、ブラウザ互換、過去の不具合の再発防止など。
- 1 行に収める。長くなるなら設計の問題なのでコードを直す。

```ts
// NG: 挙動の説明
// fontsource の @font-face は swap 固定で、optional にすると初回はフォールバックで描画し 2 回目以降は Web フォントで描く
// OK: 理由だけ
// fontsource は swap 固定でフォント到着時にチラつくため optional に差し替える
```
