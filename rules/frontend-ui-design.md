# frontend UI デザインルール

参照: [Figma 基礎資料](https://www.figma.com/design/KIz51olPtwpG8lU3xObA8s/times?node-id=12-4)
値の正は `frontend/src/app/styles/global.css` のトークン。ここには値を書かない。

## 原則

- Slack のチャンネルの構造を借りる。サイドバーはチャンネル一覧、メインは日付区切り + bot (`z-times`) の 1 日 1 投稿。色は Slack を真似ない。
- メインは白背景 + 1px 境界線。カード、入力欄、メニュー、ログインカードすべて同じ。
- サイドバーだけ濃色 1 面 (`--color-sidebar-bg`)。文字は白系、ホバーと選択中は背景の差だけで表す。
- 有彩色はオレンジ 2 段だけ。ロゴ色 `--color-brand` はロゴのタイル・bot アバター・`.dev`・トップのカテゴリアイコンに、操作色 `--color-accent` (`--color-brand` の別名。白地で 2.8:1 と AA 未達は承知のうえ、adr/frontend/0003) はリンク (Digest の記事リンクはホバー時のみ)・選択中チャンネル・ステータスに使う。トップのヒーローの地だけ薄いオレンジ `--color-brand-faint` を敷く。他の有彩色は使わない。
- ロゴは `docs/logo.svg` が元データで、`shared/ui/logo.tsx` はその写し (オレンジのタイル + 白 `Z` + 黄ドット + Arial Rounded のワードマーク `z_times.dev`)。元 SVG のアニメーション (文字の傾き、`.dev` の落下、ベル、ドット) はサイドバーの `variant="hover"` でだけ再生する。普段はアイコンだけで、アイコンのホバー中に文字をフェードインさせる。トップの h1 (`variant="hero"`) は静止画。favicon は `public/favicon.svg` (アイコン部分のみ)。コンセプトと要件は adr/frontend/0004。
- 状態は枠線・背景の濃淡・小さな影・アクセント色だけで表す。グラデーション、強い影は使わない。
- 操作領域 (入力欄・ボタン) は角丸で区切り、本文や一覧と見た目で区別する。
- 色・影・角丸・余白はトークンで指定する。CSS Modules に生の値を書かない。
- 余白は 8 の倍数。画面パディングとセクション間は `--space-4`、カード内は `--space-2` 〜 `--space-3`。

## タイポグラフィ

フォントは Klee One (body で指定済み)。用途別に `global.css` のクラスを使う。CSS Modules からは `composes: t-title from global;` で取り込む。

記事タイトル・プレビュー・入力欄など、データ由来の文字を出す要素には `font-family: var(--font-dynamic);` を付ける。body の既定はソース中の固定文字だけを含むサブセットで、それ以外の字は端末のフォントになる (adr/frontend/0005)。

| 用途 | クラス | サイズ / ウェイト |
|---|---|---|
| 日付見出し | `.t-date` | 18px / 600 |
| カテゴリ見出し | `.t-label` | 14px / 600 |
| 記事タイトル | `.t-title` | 16px / 400 / line-height 24px |
| カード本文 | `.t-body` | 13px / 400 / line-height 1.5 |
| メタ (ドメイン・時刻) | `.t-meta` | 11px |

複数ページで同じ複合ブロック (見出し + メタなど) が出るまで React コンポーネントには昇格させない。

## 投稿 (Digest) の構造

- 日付は線の中央にピル (`.t-label` + 境界線 + 角丸 9999px)。日付は `10月20日(火)` の形で出す。
- 1 日分が 1 投稿。左にアバター (36px、`/favicon.svg`)、右に `z_times.dev` とカテゴリごとの小見出し + 記事行。投稿時刻は出さない。
- 記事行は favicon を行頭マーカーにする。箇条書きの記号は付けない。子記事は左 1px 線でインデント。
- 記事タイトルのリンクは普段 `--color-text` で下線を付けず、ホバーとフォーカス時だけ `--color-accent` にする。記事が並ぶ面でオレンジが散らばらないようにするため。行全体がリンクで、行頭の favicon が目印になるので下線は不要。
- 記事カード (OG プレビュー) はホバー時だけ出す。常時表示はしない。

## トップページ (入り口)

- `/` はシェル (サイドバー) の外。チャット UI の中では「何のアプリか」が伝わらない (adr/frontend/0003)。
- 構成は 3 つの面。ヒーロー (`--color-brand-faint`、中央寄せ: ロゴ (`<Logo hero />`) + 説明 1 文 + 投稿ブロック + 使い方のヒント 1 行) → 「ゆるい説明」(白地: リード + カテゴリ一覧 + 気になりそうなこと) → フッター (白地: ロゴ + GitHub)。面の切り替えは色と 1px 線だけで、波線などの装飾は入れない。ヘッダーは置かない。
- 「何のサイトか」はヒーローの説明文だけに書く。リードはセクションの案内、FAQ はヒーローで言っていないこと (見方・過去分・更新頻度・運営者) に答え、定義を繰り返さない。
- 文言は話し言葉 (「〜してます」) にする。業務アプリやサービス紹介の硬さを出さないため。
- `--color-brand-faint` の上では `--color-text-faint` が 4.5:1 を切るので、文字は `--color-text-muted` 以上にする。
- 投稿ブロックは浮かせたカード: 白地 + 境界線 + `--radius-panel` + `--shadow-raised`。帯は付けず、上端に日付ピルと件数 (`.t-meta` の muted)、その下に投稿。更新は不定期なので「毎日」など頻度を言い切る文言は出さない。チャンネル名 (`#…`) は出さない。
- ヒント (プレビューの案内) はホバーできる環境でだけ出す。
- カテゴリ一覧は 1 つずつ境界線 + `--radius-control` の枠に入れ、幅に合わせて折り返すグリッドに並べる。名前の前に animate-ui の単色アイコン (`--color-brand`) を置き、枠のホバーで 1 回動かす。よくある質問は button (`aria-expanded`) + grid の高さ補間で開閉し、最初の 1 問だけ開いておく。`<details>` は閉じる側をアニメーションできないので使わない。
- 表示は最新の 1 日分だけ。
- カードは 1 画面に収まる高さで折りたたみ、収まらない日だけ下端をフェードさせて「すべて表示」ボタン (白地 + 境界線 + `--radius-control`、`.t-body` の muted) を出す。内部スクロールは使わない (入れ子のスクロールは操作しづらい)。展開後に折りたたみ直すボタンは置かない。
- 折りたたみ時はヒーローごと窓の高さに収める (PC・タッチ共通)。下限は `.fit` で 320px (スマホ横向きでも記事が数行見える高さ)。プレビューは画面基準で上下を反転し、カードの外にはみ出してよい。モバイルと高さ 480px 以下 (スマホ横向き) はヒーローの上下余白を `--space-4` に詰める。
- フェードは高さを測る前 (SSR) から出し、フェードにかかる記事リンクはポインター操作を受けない。展開ボタンだけ計測後にアニメーションで出す。
- 過去 Digest のタイムライン画面ができるまで、ブロックからシェルへの導線 (扉) は置かない。

## レスポンシブ

- モバイル (`--mobile`) では入力欄と追加ボタンを 1 行にまとめ、カードはタイトル優先で短くする。
- 白背景・境界線・角丸・トークンは PC とモバイルで共通。サイドバーはモバイルではオーバーレイで出す。
- サイドバーとモバイルヘッダーはログイン中だけ出す。未ログインはトップも `_shell` 配下もメインのみ。
