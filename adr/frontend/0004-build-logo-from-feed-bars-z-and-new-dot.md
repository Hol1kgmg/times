# ロゴは「フィードで組んだ z + 新着ドット」で作り、形の正はコードに置く

## Context and Problem Statement

サイト名を `z_times.dev` にしたが、favicon とヘッダーに置けるロゴが無かった。文字だけのサイト名では、サイドバーの濃色面でもトップの h1 でも「何のサイトか」が伝わらない。

要件 (インタビュー):

| 項目 | 内容 |
|---|---|
| 内容 | IT の技術記事やニュースのサイトを一覧化して、毎日届ける情報サイト |
| ターゲット | Web アプリ開発エンジニア |
| 伝えたいこと | `z_times` は毎日情報に触れられる場所、`.dev` はエンジニア向け |
| 印象 | 手軽・気軽・ライト層向けのカジュアルさ、親しみやすさ |
| 色 | おまかせ |
| 避けたいもの | 堅すぎる・重厚な表現。16px で潰れる細かい表現 |
| 使用場所 | favicon (アイコン部分のみ)、ヘッダーやトップ (アイコン + 文字) |

## Decision

**「フィードで組んだ z + 新着ドット」のアイコンに、`z_times` を主役・`.dev` を添え物にしたワードマークを付ける。形・寸法・色・アニメーションの正は `docs/logo.svg` とその写しである `frontend/src/shared/ui/logo.tsx` に置き、この ADR には数値を書かない。**

- アイコン: 記事一覧の行 (太いバー) で `z` を組み、右上に新着ドットを置く。バーは「毎日のフィード」、ドットは「今日も新しい情報が届いた」を表す。角丸タイル 1 枚にまとめ、単体で favicon に使う
- 色: タイルはオレンジ (`--color-brand`)、ドットはイエロー。親しみやすさと「新着」の目立ちを色で分ける。他ページのリンクや選択中チャンネルには、白地でコントラストを満たす濃いオレンジ (`--color-accent`) を使う (adr/frontend/0003)
- ワードマーク: 丸ゴシック系の太字 (Arial Rounded 系)。カジュアルさを出し、Klee One の本文と役割を分ける。`z_times` が主役、`.dev` は小さくアクセント色で同じ基準線に添える。ワードマークの高さはアイコン高さの約 7 割
- 形式: アイコン + ワードマークの横組み 1 種類。縦組みやモノクロ版は使う場所ができるまで作らない
- アニメーション (2026-10-22 からサイドバーのアイコンのホバー時。下の More Information を参照): コンセプトは「`.dev` に関する情報が降ってきて、アイコンがそれを通知する」。順に、`.dev` がフェードイン → 落下して着地し横につぶれる → `z_times` が驚いて身を引く (下端を固定して上側を傾ける) → ベルが揺れながら現れる → `.dev` と `z_times` が押されてずれる → ベルが消えてドットが残る。初期状態にはドットと `.dev` が無い。テンポよく、動きと動きの間に間延びを作らない。`prefers-reduced-motion` では動かさず最終状態を出す
- 管理: 形を変えるときは `docs/logo.svg` を直してから `logo.tsx` に写す。favicon は `frontend/public/favicon.svg` にアイコン部分だけを切り出す

## Consequences

- 良い: favicon とロゴが同じアイコンなので、タブとページで同一性が出る
- 良い: アイコンはバー 3 本とドットだけで、16px でも潰れない
- 良い: アニメーションがサイトの「毎日通知が来る」性格を説明する。トップに説明文を置く量を減らせる
- 悪い: SVG と React の二重管理。keyframe の割合や座標を片方だけ変えるとずれる。差分は両方を同じコミットに含める
- 悪い: ワードマークのフォントは環境依存 (Arial Rounded MT Bold は macOS 以外に無いことが多い)。OGP 画像にするときはパス化が要る (TODO.md)
- 悪い: アニメーションはサイドバーのホバーにだけ付けており (2026-10-22)、トップの h1 とモバイルヘッダーでは静止画。未ログインの訪問者はアニメーションを見られない

## Alternatives Considered

- **文字だけのワードマーク**: favicon にできない。Klee One では濃色面で弱く、「情報サイト」の性格も出ない
- **アイコンにベルや紙飛行機など通知のモチーフを常時置く**: 「通知アプリ」に見える。ベルはアニメーションの一瞬だけに留め、静止状態はフィード (バー) + 新着 (ドット) にした
- **寸法と色をこの ADR に書く**: 書いた直後から調整で数値がずれ、ADR が古くなる。数値はコードが正で、ADR は意図と比率の目安だけ持つ
