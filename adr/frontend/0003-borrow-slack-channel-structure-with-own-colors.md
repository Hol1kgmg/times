# Slack のチャンネルの構造を借り、色は独自のネイビー 1 色にする

## Context and Problem Statement

サイト名を `z-times` にし、「Slack の #times チャンネルに毎日技術記事が投稿される」雰囲気を出したい。それまでの UI は白背景 + 1px 境界線だけで、サイドバーもメインも同じ白面だった。日付・カテゴリ・タイトルの一覧はあるが「投稿された感」が無い。

制約:

- 色・影・角丸はトークンで指定し、CSS Modules に生の値を書かない (constitution)
- フォントは Klee One。手書き感のある書体で、暗い面では弱まる
- 記事の OG 画像は白地が多く、全面ダークだと浮く
- 個人サイトなので、ダークモードの二重管理は後回しにして良い

## Decision

**構造だけ Slack から借り、色は独自にする。**

- サイドバー = チャンネル一覧 (濃色 1 面)、メイン = 日付区切りピル + bot (`z-times`) の 1 日 1 投稿。メインは白背景 + 1px 境界線のまま
- サイドバーはインクネイビー (`--color-sidebar-bg`)。有彩色はロゴのオレンジだけ。ロゴ色 `--color-brand` (#ff6b35) はロゴとアバターに、リンク・選択中チャンネル・ステータスは白地で 4.5:1 を満たす濃いオレンジ `--color-accent` (#c2410c) にする。原色は白地で 2.8:1 しかなく、本文リンクには使えない。`--color-status` はアクセントの別名にする
- 1 日分の Digest を 1 投稿にする。記事ごとに投稿を分けると bot のアバターが 10 回並んで冗長で、データ構造 (Digest = 1 日分) とも一致しない
- 記事行は favicon を行頭マーカーにし、箇条書きの記号は付けない
- OG プレビューカードはホバー時だけ出す。常時展開 (Slack の unfurl) は 1 日分が画面に収まらなくなる
- ダークモードは TODO。サイドバーとアクセントの dark 値を決めるまで既定値のみ
- トップ (`/`) はシェルの外に置く。チャット UI は見た目そのものが「会話ツール」と語り、初見の人に「何のアプリか」が伝わらない。トップはサイト名 + 説明 + 最新 Digest の投稿ブロック (パネル枠 + 影) で、投稿ブロックがアプリの中身の見本を兼ねる。シェルは `_shell` 配下のページ (管理画面、将来の過去 Digest タイムライン) で使う

## Consequences

- 良い: 「毎日投稿される」感がアバター + 名前 + 日付ピルで出る。過去 Digest を並べたとき「区切り → 投稿」が日ごとに繰り返されてタイムラインになる
- 良い: 変更はトークン 5 つとサイドバー・ホームの CSS だけで、他ページは触らない
- 悪い: Figma の基礎資料が旧デザイン (白サイドバー) のまま。更新するまで Figma とルールが食い違う
- 悪い: dark トークンがメイン側だけなので、`prefers-color-scheme: dark` でサイドバーとメインの境界が消える可能性がある

## Alternatives Considered

- **Slack 本家の紫サイドバー + 青リンク**: 一目で Slack と分かるが、紫の印象が強すぎて z-times の色にならない。模倣感が出る
- **全面ダーク (Slack のダークモード風)**: 技術記事フィードには合うが、OG 画像の白地が浮き、Klee One の手書き感が弱まる
- **1 記事 1 投稿**: Slack らしいが、アバターと名前が記事数だけ並ぶ。投稿時刻のデータも無く、ヘッダーに出す情報が無い
- **unfurl の常時表示**: 1 投稿が 200px を超え、1 日分が 1 画面に収まらない
- **トップもシェル内にして、チャンネル冒頭に説明を置く**: デザインが 1 つで済むが、説明がチャットの遺物に見え、サイドバーと投稿の並びを見た時点で Slack のクローンだと解釈される。説明文はその第一印象に負ける
