# Quickstart: 記事を外部の AI チャットで解説してもらう

## 前提

- `just be-dev` と frontend の開発サーバーが動いていて、公開済みの Digest が 1 件以上ある
- タイムラインの確認には管理者でログインしておく (specs/008)

## 自動の確認

```sh
just lint && just test   # ai-chat.test.ts (文の形と URL の符号化)
just fe-typecheck        # 編集画面のプレビューに ai を渡せないこと
just fe-lint-markup
```

e2e は回さない。サーバー関数・backend・SQL・セッションに触れないため (quality.md)。

## 手で確かめる

### PC (ホバーできる環境)

1. トップの記事行にポインターを載せる → タイトルのすぐ右にアイコンがにゅっと出る。HOT の行では炎と吹き出しがアイコンの幅だけ右へずれる。外すと炎がタイトルの直後に戻る (spec US1-1, 2)
2. 行末ぎりぎりで折り返す HOT の記事 (幅を変えて作る) で、ホバーの前後に折り返しと行の高さが変わらず、下の記事が動かない (SC-003)。炎と吹き出しを押しても記事は開かず、炎の上では揺れと吹き出しが止まる (US1-8)
3. アイコンへポインターを移す → カードが出る。アイコンからカードへ動かしても消えない。外へ外すと少し後に閉じる (US1-3, 4, 9)
   - タイトルとアイコンの間の隙間、タイトルが折り返した先の行の上でアイコンが消えない。炎と吹き出しの上ではアイコンが出ない (FR-002)
   - アイコンの縁 (上端や角) にポインターを置き続けても、カードが開閉を繰り返さない (research R2)
   - タイトルの上ではカードが開かず、プレビューだけが出る
4. 「Claude で解説」→ 新しいタブの Claude の入力欄に、記事のタイトルと URL を含む依頼が入っている (US1-5、research R1)
5. 「ChatGPT」「Grok」→ 同じく入っていて、ChatGPT は自動では送信されない (US1-6)
6. 「プロンプトをコピー」→ コピーボタンの上に「コピーしました」が出て消え、カードは開いたまま。貼り付けると 4 と同じ文 (US4)
7. Tab で記事リンクへ移る → アイコンが出る。次の Tab でアイコンに止まり (読み上げはタイトル → AI → HOT の順)、Enter でカードが開いて Claude にフォーカスし、左右キーでサービスを、Tab でコピーへ移れる。Esc で閉じるとフォーカスがアイコンに戻る (SC-005)
8. アイコンを押しても記事は開かない。記事リンクを押すとこれまでどおり開く (US1-7, 8)

### ホバーできない環境 (DevTools の端末のエミュレーションでタッチにする)

1. トップを開く → 記事行にアイコンはなく、日付の線の右端はコピーボタンではなく暗い `bot-off` のトグル (US2-1)
2. トグルを押す → 明るい `bot-message-square` に変わり、1 回動き、全記事行にアイコンが出る。タイトルの位置は動かない (US2-2、SC-003)
3. 行のアイコンをタップ → カードが出る。外をタップすると閉じる (US2-3, 4)
4. もう一度トグル → 斜線が引かれて OFF、アイコンが消える。読み直すと OFF (US2-5, 6)
5. タイムラインで、ある日付のトグルを ON → 別の日付も ON になる (US3)

### 出さないこと

- 編集画面のプレビューに、アイコンもトグルも出ない
- `prefers-reduced-motion: reduce` にすると、アイコンが動かない
