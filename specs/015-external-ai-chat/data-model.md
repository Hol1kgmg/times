# Data Model: 記事を外部の AI チャットで解説してもらう

保存するデータはない。DB・OpenAPI・サーバー関数は変えない。ブラウザの中だけで作って渡す値を次に書く。

## 依頼の文 (プロンプト)

| 入力 | 型 | 出どころ |
|---|---|---|
| title | string | 記事 (`NewChildArticle.title`)。親の記事も子の記事も同じ |
| url | string | 記事 (`NewChildArticle.url`) |

- 文の形 (固定。3 つのサービスとコピーで同じ文を使う):

  ```text
  次の記事を日本語でわかりやすく解説してください。要点と背景、読むのに必要な用語を教えてください。記事を読めないときは、推測で答えずにその旨を教えてください。

  タイトル: {title}
  URL: {url}
  ```

- 公開済みの記事の title と url は、backend の検証を通った値 (title は空でない、url は URL の形)。ここで検証し直さない (quality.md「同じ契約に照らして再検証しない」)

## 外部の AI チャット

| id | 表示名 | 開く URL |
|---|---|---|
| `claude` | Claude で解説 | `https://claude.ai/new?q={文}` |
| `chatgpt` | ChatGPT で解説 | `https://chatgpt.com/?q={文}` |
| `grok` | Grok で解説 | `https://grok.com/?q={文}` |

- `{文}` は `URLSearchParams` で符号化する (改行・`&`・`#` を含んでも壊れない)
- 計測用のパラメータや読み手を識別する値は付けない (spec FR-017)

## アイコンの表示状態

| 値 | 意味 |
|---|---|
| `false` (初期値) | ホバーできない環境で、記事行のアイコンを出さない |
| `true` | ホバーできない環境で、全記事行にアイコンを出す |

- ページの部品ごとに 1 つ。保存しない
- ホバーできる環境では使わない (行のホバーとフォーカスで出す)
