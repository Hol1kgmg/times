# Feature Specification: 404 の背景を 3D の favicon の立方体にする

**Feature Branch**: `feat/not-found-3d`

**Created**: 2026-11-13

**Status**: Draft

**Input**: User description: Issue #150。404 の背景で favicon を落として積もらせる演出を、奥行きのある 3D に作り直す。サイトのオレンジの格子線でできた床を斜め上から見下ろし、最新の Digest の記事の favicon を面に貼った立方体が、回転しながら落ちて跳ね、山に積もる。404 の文言とトップへのリンクはいつでも読めて押せる。数は無限に増やさず、動きを減らす設定・3D を描けない環境・画像の取得失敗・スマートフォンでも崩れない。関連: #74、#133。

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 見つからないページでもトップへ戻れる (Priority: P1)

存在しない URL を開いた人は、背景の演出にかかわらず、大きな「404」・見出し・1 文・トップへのリンクを読み、リンクを押して最新の Digest へ戻れる。キーボードとスクリーンリーダーでも同じように使える。

**Why this priority**: 404 の役目そのもの。演出が戻る手段を邪魔すれば作り直す意味がない。

**Independent Test**: 存在しない URL を PC とスマートフォンの幅で開き、演出の途中と積もり終わった後の両方で、文言が読めてリンクを押すとトップに移ることを確認できる。

**Acceptance Scenarios**:

1. **Given** 存在しない URL, **When** 開く, **Then** 背景の描画を待たずに「404」・見出し・1 文・トップへのリンクが出る
2. **Given** 立方体が落ちている途中, **When** トップへのリンクを押す, **Then** トップに移る (立方体がリンクの上に重なっていても押せる)
3. **Given** キーボードだけで操作している, **When** Tab を押す, **Then** トップへのリンクにフォーカスが移り、背景の要素には止まらない
4. **Given** スクリーンリーダーを使っている, **When** ページを読み上げる, **Then** 案内の文とリンクだけが読まれ、背景の演出は読まれない
5. **Given** 幅 320px から PC の幅まで, **When** 窓の大きさを変える, **Then** 案内の文とリンクは山に隠れず、横にはみ出さない

---

### User Story 2 - 奥行きのある床に favicon の立方体が降り積もる (Priority: P1)

404 を開くと、オレンジの格子線の床が斜め上から見下ろす奥行きで描かれ、最新の Digest に載った各サイトの favicon を面に貼った立方体が、上の不規則な位置から次々に現れて回転しながら落ちる。床やほかの立方体に当たると小さく跳ね、止まって山になる。

**Why this priority**: この機能で新しく加える体験の中心。

**Independent Test**: 最新の Digest がある状態で 404 を開き、床に奥行きがあること、立方体の面に記事のサイトの favicon が見えること、落ちて跳ねて止まり山になることを目で確認できる。

**Acceptance Scenarios**:

1. **Given** 最新の Digest に記事がある, **When** 404 を開く, **Then** オレンジの格子線の床が奥へ向かって細かく見え、手前が大きく見える
2. **Given** 演出が始まった, **When** 見ている, **Then** 立方体は上の不規則な位置から間をおいて現れ、回転しながら落ちる
3. **Given** 立方体が床かほかの立方体に届いた, **When** 着地する, **Then** 小さく跳ねてから止まり、床や別の立方体にめり込んだり震え続けたりしない
4. **Given** 立方体が積もっていく, **When** 終わりまで見る, **Then** 平らな層ではなく山の形になる
5. **Given** 立方体の面, **When** 見る, **Then** 最新の Digest に載ったサイトの favicon が、縦横比を崩さず各面に同じ絵で貼られている
6. **Given** 同じ最新の Digest のまま, **When** 404 を何度か開き直す, **Then** 毎回同じ形の山になる

---

### User Story 3 - どの環境でも 404 として崩れない (Priority: P2)

動きを減らす設定の人、3D を描けない端末やブラウザの人、favicon が取れないときも、404 の案内はそのまま使え、背景は破綻しない。長く開いたままでも重くならない。

**Why this priority**: 演出は飾りなので、出せない環境で案内まで壊れては本末転倒。ただし案内そのものは Story 1 で守られるので、背景の出し方は P2。

**Independent Test**: 動きを減らす設定、3D を描けない環境、オフラインで favicon が取れない状態、スマートフォンの幅で 404 を開き、案内が使えて背景が崩れていないことを確認できる。

**Acceptance Scenarios**:

1. **Given** 動きを減らす設定, **When** 404 を開く, **Then** 立方体は落ちず、積もり終わった山が最初から止まった絵で出る
2. **Given** 3D を描けない環境、または描く準備に失敗した, **When** 404 を開く, **Then** 案内は普段どおり出て、背景は 3D なしの代わりの絵になる (エラーは表示しない)
3. **Given** 一部のサイトの favicon が取れない, **When** 404 を開く, **Then** その立方体は代わりの絵 (サイトの favicon を表示できないときの共通の絵) で出る
4. **Given** 最新の Digest が取れない、または記事がない, **When** 404 を開く, **Then** 立方体は出さず、床と案内だけが出る
5. **Given** 404 を長く開いたまま, **When** 時間がたつ, **Then** 立方体の数は上限で止まり、増え続けない
6. **Given** 別のタブに切り替えていた, **When** 戻る, **Then** 離れていた間の動きを一度に進めて跳ばず、続きから動く
7. **Given** スマートフォンの幅, **When** 404 を開く, **Then** 床の見える範囲・立方体の大きさと数を画面に合わせて減らし、案内を隠さない

### Edge Cases

- favicon が 1 種類しかない: すべての立方体が同じ絵になる (山は成り立つ)
- favicon が非常に多い (記事が数十サイト): 使う種類に上限を設け、超えた分は使わない
- favicon に透明な部分がある: 透明な部分から立方体の地 (サイトの面の色) が見え、裏の面は透けない
- 立方体が落ちている途中で窓の大きさが変わる: 案内は隠れない。山は大きさを測り直さず、はみ出た分は切ってよい
- 落ちている途中で別のページへ移る: 演出を止めて片付け、移った先に影響を残さない
- ダークモード: 床の線と地の色はサイトのダークモードの色に従う
- 演出の準備 (画像の読み込みなど) に時間がかかる: 案内は先に出て、背景は準備が済んでから始まる

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 404 の案内 (「404」・見出し・1 文・トップへのリンク) は、背景の演出の有無や進み具合にかかわらず、すべての画面幅で読めて押せなければならない
- **FR-002**: 案内は背景の描画を待たずに、サーバーから返す最初の表示に含めなければならない
- **FR-003**: 背景の演出は飾りとして扱い、読み上げ・キーボードのフォーカス・ポインター操作の対象にしてはならない
- **FR-004**: 背景には、サイトのオレンジの格子線でできた床を、斜め上から見下ろす奥行きで描かなければならない。床の線と地の色はサイトの色の決まり (ライト・ダークとも) に従う
- **FR-005**: 立方体の面には、最新の Digest に載った記事 (子記事を含む) のサイトの favicon を、サイトごとに 1 種類、縦横比を保って各面に同じ絵で貼らなければならない
- **FR-006**: favicon を表示できないサイトの立方体には、サイト全体で favicon の代わりに使っている共通の絵を貼らなければならない
- **FR-007**: 最新の Digest が取れない、または記事が 1 件もないときは、立方体を出さず床と案内だけを出さなければならない
- **FR-008**: 立方体は上の不規則な位置から間をおいて現れ、回転しながら落ち、床やほかの立方体に当たると小さく跳ねてから止まらなければならない。止まった後に震えたり、ほかの立方体や床にめり込んだりしてはならない
- **FR-009**: 積もった立方体は中央が高い山の形にならなければならない。同じ最新の Digest なら、開くたびに同じ形にならなければならない
- **FR-010**: 新しい立方体は、一定の時間か一定の数、または山が画面の上端に近づいたところで出すのを止めなければならない。立方体の数と使う記憶領域は、開いている時間に比例して増えてはならない
- **FR-011**: 動きを減らす設定のときは、落ちる動きを出さず、積もり終わった山を止まった絵で出さなければならない
- **FR-012**: 3D を描けない環境、または描く準備に失敗したときは、案内を普段どおり出し、背景を 3D なしの代わりの絵にしなければならない。エラーを利用者に見せてはならない
- **FR-013**: ページが見えていない間 (別のタブなど) は動きを止め、戻ったときに離れていた時間分を一度に進めてはならない
- **FR-014**: 狭い画面では、床の見える範囲・立方体の大きさ・数を画面に合わせて調整し、案内を山で隠してはならない
- **FR-015**: 404 から別のページへ移ったときは、演出を止めて使っていた資源を解放しなければならない
- **FR-016**: 背景の演出に必要なものは 404 を開いたときだけ読み込み、ほかのページの読み込みを重くしてはならない

### Key Entities

- **立方体**: favicon を貼った 1 つの飾り。どのサイトの絵か、現れる順番、着地する位置、回転の向きを持つ
- **山**: 立方体の着地する位置の集まり。最新の Digest から決まり、同じ Digest なら同じ形になる

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 幅 320px から 1920px のすべての幅で、演出の途中と積もり終わった後のどちらでも、トップへのリンクを 1 回の操作で押せる
- **SC-002**: 一般的な PC で、演出の間の表示が 60fps 前後で滑らかに動く。スマートフォンでは 30fps を下回らない
- **SC-003**: 404 を 10 分開いたままにしても、立方体の数は上限を超えず、使う記憶領域は開いた 1 分後と比べて増え続けない
- **SC-004**: 動きを減らす設定、3D を描けない環境、favicon が 1 つも取れない状態の 3 つすべてで、案内が表示されエラーが出ない
- **SC-005**: 404 以外のページを開いたときに読み込む量は、この機能の前と変わらない
- **SC-006**: 404 を開いてから案内が出るまでの時間は、この機能の前と変わらない (背景の準備を待たない)

## Assumptions

- 物の当たりは、本物の物理計算ではなく「先に決めた着地点へ向かって落ち、着地で小さく跳ねる」見た目で表す。今の 404 と同じく山の形を先に決めることで、開くたびに同じ山になり、めり込みや震えも起きない。本物の衝突 (崩れる・転がる) は求めない。ただし格子にそろって見えないよう、出る位置・間隔、着地したマスの中の位置と向きを乱数でばらつかせる (めり込まない範囲)
- 立方体は使い回さず、上限に達したら出すのを止める (今の 404 と同じ)。Issue の「古いものを再利用・削除する」は、出し続ける場合の対策なので不要
- favicon の取り方・代わりの絵・最新の Digest の取り方は今の 404 のものをそのまま使う
- 「3D なしの代わりの絵」は今の 404 の 2D の山にする (ユーザーが決定)
- 3D の描き方の比較 (Issue の BundleGroup などの計測) は plan で行い、結果を plan に残す。仕様には描き方を書かない
- カメラの角度・格子の密度・立方体の大きさと数の具体的な値は plan と実装で決め、`.agents/rules/frontend-ui-design.md` の 404 の節を書き換える
- 対象の端末は、今サイトが動いている PC とスマートフォンのブラウザ
