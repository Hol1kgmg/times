# Data Model: 404 の背景を 3D の favicon の立方体にする

保存するデータはない。404 を開いたときにブラウザの中で作る値だけ。

## Block (立方体 1 個)

`buildStack` が返す。並びは出現の順。

| 項目 | 型 | 意味 |
|---|---|---|
| `x` | 整数 | 横の列 (0 〜 width-1) |
| `z` | 整数 | 奥の列 (0 〜 depth-1) |
| `level` | 整数 | 段 (0 が床) |
| `offset` | 2 つの -0.5 〜 0.5 | マスの中で横・奥にずらす量 (`yaw` で回した後に残るマスとの隙間に対する割合。隣とめり込まない) |
| `yaw` | -0.5 〜 0.5 | 着地したときの Y 軸の回転 (1 マスに収まる最大の回転に対する割合) |
| `spin` | 3 つの -0.5 〜 0.5 | 出現したときの 3 軸の回転 |
| `drift` | 2 つの -0.5 〜 0.5 | 出現したときの着地点からの横・奥のずれ。落ちる前半で着地点の真上に寄せる |
| `gap` | 0 〜 1 | 前の立方体から出るまでの間隔 (平均の間隔の 0.3〜1.7 倍) |

- どの favicon を貼るかは、出現の順 `i` から `i % 種類の数` で決める (今の 404 と同じ)
- 同じ `(width, depth, layers, limit, seed)` なら同じ並びになる
- `level` が `layers` に届いたら、それ以上作らない。数は `limit` まで

## 時間の流れ

| 状態 | 条件 | 位置 |
|---|---|---|
| 出る前 | `t < start` | 描かない (行列を 0 に縮める) |
| 落下 | `start ≤ t < start + fall` | `dropY` の ease-in、回転は `spin` から `yaw` へ |
| 跳ね返り | 着地の後 0.3s | `dropY` の減衰する跳ね返り、`rest` より下に行かない |
| 静止 | それ以降 | `rest`、`yaw` |

全ての立方体が静止したら、描画のループを止める。
