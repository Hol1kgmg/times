# Quickstart: 記事の再掲載と関連記事

## 前提

```sh
just db-up
just db-migrate up   # 000013 まで
just db-seed
just be-dev          # 別のターミナル
just fe-dev          # 別のターミナル
```

## 1. 移行で表示が変わらない (FR-015, SC-005)

1. 移行の前に、トップとタイムラインで親子・HOT・並びのある Digest を開いて控える
2. `just db-migrate up` のあと、同じ画面を開き、控えと同じであることを確かめる

## 2. 再掲載を登録する (US1)

1. 公開済みの Digest に載っている記事 A の URL を控える
2. `/admin/digests/new` で A より後の日付を選び、A の URL と新しい URL B を入れ、B を A の関連記事にして公開で登録する
3. 断られて同じ画面に留まり、A の行が元のタイトルの再掲載に切り替わって「再掲載にしました」と「再掲載 · 〜に初掲載」(元の日付) が出ることを確かめる。A の行のメニューは「削除」だけになる
4. もう一度登録すると通ることを確かめる
5. B を外すと A が元のカテゴリの箱へ戻り、ドラッグしても戻ることを確かめる (子のない再掲載は元のカテゴリに固定される)

## 3. 当日の表示 (US2)

1. トップで A が細い行 (小さな favicon・「再掲載」の印・1 行で省略) になり、その下に B が普通の大きさで並ぶことを確かめる。投稿のカテゴリは B のカテゴリ
2. 子のない再掲載は普通の大きさのまま印だけ付くことを確かめる
3. タイムラインで元の日の Digest を見ると、A に B が付いておらず、A のタイトルも変わっていないことを確かめる

## 4. 子の HOT (FR-016〜018)

1. 編集画面で HOT でない親の子のメニューから「ホットにする」を選んで保存し、トップでその子の行にだけ炎と吹き出しが出ることを確かめる
2. 親を HOT にすると子のメニューから「ホットにする / 外す」が消え、トップでは親の行にだけ印が出ることを確かめる

## 5. 断られる (US3)

| 操作 | 期待 |
|---|---|
| A を別の記事の子として登録 | A の行に「既に登録済みです」 |
| 下書きか非公開の Digest にだけ載っている記事を親にして登録 | その行に「既に登録済みです」(再掲載には切り替わらない) |
| 再掲載に切り替えた後、別のタブで元の Digest を非公開にしてから登録し直す | A の行に「この記事は再掲載できません」 |

## 6. 元の Digest の状態を変える (Revision 2・3)

子付きの再掲載 (2 の A) は当日に掲載を持たず、子 B の親として呼び出されるだけなので、元の日から外せない。元の掲載の入れ替えは子のない再掲載 C で確かめる。

1. 3 のあと、元の日の Digest を非公開にする。当日の Digest で A が「非公開記事」として場所だけ残り、編集画面の A の行は「再掲載 · 元の Digest が公開されてないので出ません」(日付なし) でメニューが「削除」だけのままであることを確かめる (FR-021)
2. 元の日の Digest を公開に戻し、当日の Digest で A が細い「再掲載」の行に戻ることを確かめる
3. 元の日の Digest から A を外して保存すると、「子がほかの日にいる記事は外せないので、隠した行に戻しました」で断られ、A が隠した行 (「表示に戻す」付き) で戻ることを確かめる。そのまま保存すると、元の日の公開ページから A が消え、当日の Digest では「非公開記事」になる。「表示に戻す」で保存し直すと元に戻る
4. 子のない記事 C を公開の Digest 2 つ (前の日と後の日) に載せ、後の日の C を再掲載にする。前の日の Digest から C を外して保存し、後の日の Digest の編集画面で C の行が普通の記事の行になり、タイトルを編集できることを確かめる (後の日が元の掲載になる)
5. 前の日の Digest に C の URL を入れて保存すると、「既に登録済みです」で断られることを確かめる (前の日付の公開の掲載がないので再掲載にも切り替わらない)
6. 後の日の Digest の日付を前の日より前に変えて保存し、前の日の Digest に C の URL を入れて保存すると、C の行が再掲載に切り替わることを確かめる (元の掲載が入れ替わる)

## 7. Storybook のデモ

```sh
just fe-storybook
```

`shared/ui/DigestPost` の `Repost` (前の Digest を非公開にした再掲載は普通の行) / `RepostWithAskAi` / `HotPatterns` と、`pages/digest-editor/ui/LinkMeta` の `Repost` / `RepostConverted` / `RepostUnavailable` / `Registered` を開く (contracts/ui.md)。ライトとダークの両方で確かめる。

## 8. 自動テスト

```sh
just be-gen
just lint && just test        # 振り分け・toDigest・apperr の unit、rejection-of と board の Vitest
just fe-typecheck
just fe-test-e2e digest-repost digest-new digest-edit  # quality.md の手順で be-dev-e2e に切り替えて回す
```
