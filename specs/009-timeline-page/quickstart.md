# Quickstart: Digest のタイムライン画面

## 1. 自動チェック

```sh
just lint && just test      # Vitest の prependPage を含む
just fe-typecheck
just fe-test-e2e digest-new # 登録 → トップ → #timeline の最下段 (手順は quality.md「完了の判定」)
```

## 2. 手動確認

前提: `just be-dev` と `just fe-dev`、開発用 DB (`times`) に公開の Digest が 8 件以上。足りなければ `/admin/digests/new` で過去の日付を公開で登録する。

| # | 手順 | 期待 | 対応 |
|---|---|---|---|
| 1 | ログインせずにサイドバーを見る / `/timeline` を開く | `#timeline` がない / 見つからない画面 | US4 |
| 2 | ログインしてサイドバーの `#timeline` を押す | 最新の Digest が一番下に見えている (先頭に戻されない)。日付は上から古い順。`#timeline` が選択中 | US1-1〜2, R4 |
| 3 | 2 のあと、`/timeline` を再読み込み (SSR で開く) | 2 と同じく最下段が見えている | US1-2 |
| 4 | 古い日の記事にカーソルを合わせる | プレビューが出る | US1-4 |
| 5 | 上端までスクロールする | 「読み込み中」のあと古い Digest が上に足され、見ていた投稿が同じ位置に残る (Safari でも) | US2-1〜2, R3 |
| 6 | 5 を最初の Digest まで繰り返す | 7 件未満が返ったところで止まり、それ以上読み込まない。日付に重複・抜けがない | US2-4, 2-6 |
| 7 | ウィンドウを縦に大きくし (またはズームを縮め)、開き直す | 画面が埋まるまで続けて読み込む | US2-5 |
| 8 | DevTools で Offline にして上端までスクロール | 「読み込めませんでした」と再試行。上端でスクロールし続けても再読み込みしない。並んだ投稿は残る | US3-1〜2 |
| 9 | Online に戻して再試行を押す | 続きが上に足される | US3-3 |
| 10 | 公開の Digest が 0 件の DB (`times_e2e` を空にした状態など) で開く | 「まだ記事がないです」 | US1-5 |
| 11 | 編集画面 `/admin/digests/new` で URL を足し、プレビューを開く | 移動前と同じくプレビューが取れる | R5 の退行確認 |
