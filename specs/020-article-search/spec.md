# 記事を検索する API と管理者専用の検証ページ (issue #170)

## 利用シナリオ

1. 管理者はタイトルか URL の一部で、公開の Digest に載った記事を全期間から探せる。
2. 結果は記事ごとに 1 件で、初掲載日と再掲載の日付、子なら親の URL を確かめられる。
3. 検証ページは URL を直接開いて使う。サイドバーにタブは出さない。

## 要件

- **FR-001**: 検索は管理者専用にする。未ログインは 401。範囲は全期間 (specs/016 FR-011)。
- **FR-002**: タイトルと URL の部分一致で、大文字小文字を区別しない。
- **FR-003**: 隠した記事と、下書き・非公開の Digest にしか載っていない記事は返さない (specs/018 FR-005 で再掲載に使えないため)。
- **FR-004**: 初掲載日は公開の掲載のうちいちばん古い日付、再掲載の日付はそれ以外の公開の掲載の日付。
- **FR-005**: 初掲載日の新しい順に、上限 50 件まで返す。

## 対象外

閲覧者向けの検索、日をまたいだ関連記事、本文の全文検索、登録・編集画面からの利用 (#171)、ページング。
